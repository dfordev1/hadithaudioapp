# Privacy policy

Effective: 24 August 2026

Hadith.to Android does not require an account and does not include advertising, analytics SDKs, location access, contacts access, or user-content upload.

## Network requests

When a reader opens online catalog content, the app requests static Arabic text, translations, timing manifests, and audio from Hadith.to infrastructure, Cloudflare R2, and jsDelivr. Those network providers may receive standard connection metadata such as IP address, user agent, requested path, and timestamp, and may retain it according to their own operational policies. The app does not add an advertising identifier or a Hadith.to account identifier to these requests.

## Data on the device

Catalog payloads are held in memory for the current app session. This release does not create accounts, accept private notes, or maintain a durable listening-history database. Android cloud backup is disabled in the application manifest.

## Sharing and sale

The app does not sell personal data. It does not send personal data to advertisers or data brokers. Static-content providers receive only the network request information described above.

## Children

The app does not knowingly collect personal information from children or any other users.

## Changes and contact

Material changes will be recorded in this repository before a new production release. Questions can be opened through the [Hadith.to Android issue tracker](https://github.com/dfordev1/hadithaudioapp/issues).
